# Inversiones AB Master

Sitio web estático de **master.** (Inversiones AB Master S.A.C.), venta al por mayor y menor de productos de ferretería para empresas, obras y contratistas.

Hecho con HTML5, CSS3 y Bootstrap 5.3.9, sin JavaScript propio.

## Páginas

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio: banner con fotos, garantías, categorías y cotización rápida |
| `catalogo.html` | Catálogo por categorías con disponibilidad por sede |
| `empresas.html` | Línea de crédito, despacho a obra y asesoría técnica |
| `sedes.html` | Nosotros y las 4 sedes |
| `contacto.html` | Formulario de cotización y datos de ventas |

## Carpetas

- `bootstrap/`: Bootstrap 5.3.9 (CSS y JS)
- `css/custom.css`: estilos y animaciones propias
- `assets/img/`: fotos del banner y de productos (Unsplash, licencia libre)
- `assets/docs/`: fichas técnicas en PDF

## Ver el sitio

Abre `index.html` en el navegador. No necesita instalación.
